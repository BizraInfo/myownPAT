# Changelog

## [Unreleased]

### Added

- Added the isolated knowledge fabric package with a governance-split retrieval spine: in-process ingest and sealed source store, a local TF-IDF lexical index with a term co-occurrence candidate graph, a PAT proposer that drafts cited answers with `authorityDelta` fixed to `0`, a model-blind SAT verifier that re-checks every citation against the sealed source bytes, and a DEMA surface that returns labelled results. Includes the red-first acceptance tests that a forged or unprovable citation is rejected and that no retrieved chunk may authorize an action.
- Added `SnrReranker`, an opt-in HHMM + diffusion signal-to-noise reranker that reorders PAT's lexical candidates before citation composition. It composes a 2-level Hierarchical Hidden Markov Model (coarse source state, fine position-band sub-state, query-overlap emission) producing a per-candidate posterior, a damped power-iteration diffusion amplifier that spreads relevance mass along the candidate graph to a fixed point with a memoizing hash table for O(1) repeated node walks, and a graph-of-thoughts SNR collapse `signal / (signal + noise)` bounded in `[0, 1)`. Wired into `ProposerAgent` behind `ProposeOptions.useSnrReranker` (default `false`), so the baseline TF-IDF spine behaviour and the SAT/DEMA governance invariants are unchanged: the reranker only reorders candidates, mints no authority, and cannot strengthen an answer past its weakest verified citation. Diffusion convergence budget (80 iterations, `1e-4` epsilon) is set from the measured geometric L1 decay on a small sparse graph, and mass is conserved every iteration. Includes acceptance tests for convergence, mass conservation, posterior well-formedness, monotonic bounded ranking, the hash-table memo hit, and the governance invariants holding through the reranked path.
